# OP-0006 · S13 数据积累期

> **不代表现状**：本文件是冻结的计划；现状只看 `DESIGN.md` 与 `docs/design/`。

## 要做什么

让插件按真实使用跑 1–2 周，把 0.6.7 起的观测（§14）攒成可复盘的样本。**期间不改行为、不发版。**

## 方式

- 只解除日常使用工作区的停用（隐私 / 测试工作区继续停用）；
- 确认 `autoRecall` 与提炼参数是想要的形态；
- 不刻意造数据，不为了凑 gate 去问。

## 验收（start gate，详见 `NEXT_STEPS.md` §3）

| 指标 | 门槛 |
|---|---|
| L2 记忆条数 | ≥ 100 条，其中 `source: user` ≥ 20 条 |
| 跨重启观测 | 按天汇总覆盖 ≥ 7 天、≥ 5 次重启 |
| 真实召回 | 注入 / 跳过记录 ≥ 50 次，跳过原因分布可解释 |
| 关系标注集 | ≥ 20 条（含关键负例），脱敏或合成 |
| 池子规模 | ≥ 300 条 active |

## 边界

- 评估集只用脱敏或合成内容，真实记忆正文不进仓库；
- gate 没到就不进 OP-0009（数据依赖项）。

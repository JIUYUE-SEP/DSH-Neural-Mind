# docs/ops/（计划草稿）

放**还没定稿**的设计 / 操作想法：可改、可删，不参与任何门禁，也不占 `§` 号。

流程：

1. 想法先记在 `NEXT_STEPS.md` 的「待设计池」（无编号）；
2. 决定要做时，在这里写计划草稿；
3. 评审通过 → 分配 `OP-0001` 编号 → 移到 `docs/legacy/ops/OP-0001-<slug>.md`（定稿即冻结）→ 进 `NEXT_STEPS.md` 队列；
4. 放弃：直接从本目录与待设计池删掉，不留记录。

草稿里**不写** `code:` 归属：代码归属只写在 `docs/design/` 的现行设计里；这里的东西**不代表现状**。
